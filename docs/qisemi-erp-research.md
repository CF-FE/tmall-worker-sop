# 七色米 ERP：接入能力与天猫项目适用性研究

整理日期：2026-11-08。状态：公开资料调研，不是接入方案验收。本文将官方产品介绍、第三方 MCP 线索与项目设计判断分开记录；没有连接 ERP、安装组件、创建凭据或测试真实业务数据。

## 结论

七色米可以进入 ERP 对接候选清单：官方存在模块 API 定制服务，以及订单、库存、售后同步的电商套件介绍。但这些信息不足以证明已有可直接使用的公开 API、官方 MCP，或本项目所需的天猫商品编辑与广告操作能力。

适合先核实其作为经营数据来源及企业系统协作节点的可行性。不能以“ERP 有电商套件”替代逐动作的店铺接口盘点，也不能以产品自带 AI 助手推断外部 Agent 已获开放权限。

## 优先核查清单

1. **产品与资格**：准确产品线、版本、租户、已购模块；接口是标准开放、定制交付还是服务商专用；测试环境与申请方式。
2. **接口契约**：官方目录、对象、字段、读写语义、分页、增量游标、删除事件、限流、版本与废弃策略。
3. **认证与授权**：官方端点域名、认证类型、最小权限范围、租户隔离、凭据有效期、撤销及审计；不在公开文档中保存密钥。
4. **商业条件**：评估和定制费用、订阅或调用费用、额外模块费用、维护与升级责任；不能把报价前介绍当免费承诺。
5. **数据口径**：订单/退款状态、成本组成、库存可用与锁定数量、商品/SKU 标识、来源时点、业务日和延迟。
6. **同步控制**：单向或双向、初始回补、重放与去重、冲突归属、失败补偿、人工修改与其他系统优先级。
7. **具体写动作**：哪些操作会即时改变 ERP 或平台状态，是否支持条件写、批量部分成功、请求标识查询和回读。
8. **第三方 MCP**：供应方身份、官方认可依据、源码/发行来源、端点、鉴权、工具列表、数据接收方、版本、费用和维护状态。未核实前不采纳其安装或配置指令。
9. **运营保障**：支持渠道、故障告警、日志可用范围、恢复目标、停用与数据导出/删除约定。

## 最小权限与数据边界

以下是建议的验收要求，不是已经开通的权限。

- 首次验证优先采用隔离环境及脱敏样本，只读取明确业务对象与必要字段。
- 为订单、库存、成本、商品维护和广告操作分别授权；ERP 读取权限不包含天猫写权限，商品编辑权限不包含投放授权。
- 明确 ERP、平台及其他系统各自的权威字段，尤其是可售库存、锁库和成本。禁止以历史快照机械覆盖当前库存。
- 不默认导出全量订单、客户姓名、电话、地址或售后正文；聚合指标能完成任务时优先使用聚合。
- 调用模型或第三方 MCP 前确认数据接收方、处理范围和必要授权；产品有 AI 功能不意味着可以把经营数据发送给任意模型。
- 凭据通过受控机制管理，不进入公开仓库、日志、提示词或研究卡正文。持久访问的创建或扩权须单独履行相应确认。
- 记录数据来源、截至时间、采集时间、覆盖范围及空窗，缺失值不能当零库存或零退款。

## 执行与恢复边界

未来若确认写能力，也应复用本项目 [执行与验收要求](execution-and-validation.md)：

1. 先登记动作契约，绑定对象、字段差异、最终内容、批准范围与有效期。
2. 派发前持久保存意图、证据和必要风险占用，并复核当前状态。
3. 同步接口返回成功不等于天猫展示已生效；ERP、平台和消费者侧结果分层核验。
4. 请求超时先核对原请求及实际状态，不能整批重发；未知结果保留冲突阻塞。
5. 退货、退款、订单履约与库存变化不可通过简单回写“撤销”。恢复须基于当前事实和单独批准的处置动作。
6. 平台广告仍运行时，停用 ERP/MCP 或 Agent 不等于停投；广告控制独立验收。
