## 如何使用

- 先区分官方资料、项目设计、作者经验、目标店铺实测结果。
- 文档中存在接口，不代表本店已经获得权限；教程演示不等于当前规则或收益保证。
- 每条经验必须带来源、日期、平台、适用条件、反例及验证状态，再决定是否转成 SOP。
- 写入商品、SKU、图片、价格、库存或广告前，必须取得相应授权并具备核验与接管办法。
- 本仓库公开，仅保存原创概述、公开来源链接、脱敏设计和空白模板。第三方视频、完整转写、私有原稿、真实店铺经营数据、账号凭据和客户资料不入库。
- 第三方素材权利归原权利人；公开可访问不等于获得转载或商用许可。本轮未添加可替代授权的开源许可证。

## 完成边界

本次沉淀的是研究文档。没有执行真实上架、改价、改库存、投放或下单，也没有将文档检查冒充接口测试。后续以逐动作实测结果更新状态，不用“已整理”代替“已实现”。
